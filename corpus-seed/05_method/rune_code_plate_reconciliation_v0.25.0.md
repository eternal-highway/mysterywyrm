# Rune Code Plate Reconciliation — 0.25.0

Date: 2026-08-30  
Scope: three complete full-resolution plate transcriptions and one lower-field decomposition; no structural acquisition and no continuous-message inference

## Method

Each carrier was inspected at the live page's full available source resolution and read only under the site-provided *Octave* group/place table. The physical grammar changes by page, but every encoded unit supplies a group count from one to four and a place count from one to eight. Titles, captions, chapter positions, and semantic completions were applied only after the counts. Primary media remain source-linked metadata rather than retained payloads.

## You Knew it Beforehand — lower displayed bands

The carrier grammar remains eyelash count for group and hair-strand count for place. Fifteen lower-field face coordinates separate into four displayed bands:

| Displayed band | Coordinates | Transcription |
|---|---|---|
| upper red | `4.1 1.1 3.1 3.3 1.5` | `AFTER` |
| blue pair | `2.2 1.4` | `NO` |
| mixed row | `3.5 2.3 1.1 3.3` | `LIFE` |
| skull row | `3.8 3.3 4.1 1.3` | `DEATH` |

The mechanically verified displayed order is `AFTER / NO / LIFE / DEATH`. Reordering it as `NO LIFE AFTER DEATH` is semantically obvious but not promoted without a carrier-supplied path. The earlier candidate `THERE IS NO LIFE AFTER DEATH` is rejected: `THERE IS` requires six additional units that do not exist in the lower field.

## Result and limits

The mechanically complete *Octave*-keyed plate set rises from ten to thirteen. *You Knew it Beforehand* now has a complete upper question and four verified lower word bands, but the lower sentence order remains open. These results do not establish publication, archive, folded, or chapter order as one continuous Rune Code text.
