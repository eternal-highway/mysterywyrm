# Series Coverage Audit — 0.20.0

Date: 2026-08-29  
Scope: obvious page omissions; principal compositional archives; X≠Y≠Z; Code / Rune Code; Duets; smaller cross-series

## Method

The audit compared the live entry links on eleven site-authored tag archives against `verified_page_register.csv` and the `07_capture/` canonical URLs. It kept archive membership, page capture, decoding status, publication direction, and dramatic relation separate.

## Findings

1. **One page was genuinely omitted:** *Decode*. It is the oldest live Code-archive entry and links directly `Bibliography → Decode → ᛠ`. The topology cited the latter seam, but neither the page register nor capture tree contained the source page. A compact capture now records both images, the served tags, and the `254-M` numbered filename.
2. **X≠Y≠Z was complete as pages but absent as a corpus object.** All sixteen live archive entries were already registered and captured. `x_y_z_register.csv` and `x_y_z_throughline.md` now preserve archive order, reverse-publication order, chapter placement, and the non-identical dramatic order.
3. **Code and Rune Code lacked registers.** The live Code archive contains 25 entries; Rune Code is a 17-entry subset. *Decode* belongs to Code but not Rune Code. The new register keeps page membership separate from decoding status.
4. **The Duets statement was stale.** The live archive contains fifteen entries: all fourteen reflected-pair eponyms plus *Twist*. Earlier releases correctly reported only the pages directly checked at those dates; 0.20.0 supersedes that current-state count without rewriting the historical audit trail.
5. **Translation archive state changed.** The live archive now contains 34 entries and includes `ꝥ`; *Translating Ear* still carries Translation on its page while remaining absent from the archive. The current site-wide total is therefore 35 Translation-tag pages: 29 direct rune commentaries and six auxiliary or cross-rune pages.
6. **No further entry-page omission appeared in the inspected structural archives.** Instruction Manual, Alphabet Book, Rune Casting, Stanzas, X≠Y≠Z, Duets, Code, Rune Code, Riddles, Mathematical Esoterica, Past, Future, and Letter otherwise resolve to already registered page URLs.

## Boundaries

- This is a coverage and topology audit, not an assertion that every thematic WordPress tag deserves a compositional register.
- `Riddles`, `Mathematical Esoterica`, `Past`, `Future`, and `Letter` are registered as secondary crossings. Their membership does not imply one continuous prose sequence.
- The full 262-post Claude harvest repository remains absent. The live archive comparison is independent of that repository and does not claim to rerun its image inventory.
- The 45 nonletter cipher slots remain open. X≠Y≠Z is no longer an unscoped “open strand”; it is now mapped, while any further cipher hypothesis remains unpromoted.
