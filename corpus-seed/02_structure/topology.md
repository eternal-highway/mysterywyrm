# Topology of the Book

## The verified core

The site presents a 29-member sequence folded around member 15. This produces fourteen opposing pairs and a middle that is formally unpaired. The pair matrix is in `runic_pair_matrix.csv`.

The fold is described through several non-identical figures:

- lunar waxing and waning;
- a unicursal labyrinth with a turn;
- a helix whose return is self-similar but not identical;
- a mirror and a mirror within a mirror;
- a book written forward while linking backward;
- paired walls on which the runes are marked during entrance and return.

These figures correspond, but they should not be collapsed into one generic spiral symbol.
