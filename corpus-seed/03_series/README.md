# Compositional Streams

The site defines *Letters for Titles* as an interconnected collection rather than one homogeneous genre. The following streams are provisionally separated for acquisition.

## Rune stanzas

Old English stanza, modern translation, rune name/glyph, paired chapter, image-caption relation.

## Translating

Philological and interpretive work: lexical alternatives, alliteration, manuscript loss, scribal transmission, historical inference, and deliberate translation choices.

## Rune Casting

Divinatory speech. This is not to be silently rewritten as psychological advice. Record voice, address, imperative, cited image/text, rune, chapter, and relation to the corresponding stanza.

## Instruction Manual / “How to”

Procedural compositions that make the book operative: seeing, listening, making, moving, surviving, speaking, burying, summoning, calculating, and turning.

## Alphabet Book / Letters for Titles

Roman and non-Roman letters, archaic letters, ligatures, punctuation, runes, sounds, letter substitutions, and titles. The W/ƿ/P/? gate belongs here but also exceeds this stream.

## X≠Y≠Z

A three-protagonist dialogic or roman-à-clef stream. Preserve speaker differences and dramatic sequence; do not summarize the three into a single narrator.

The complete sixteen-entry live archive, reverse-publication order, chapter placement, and non-identical dramatic order are now recorded in `01_inventory/x_y_z_register.csv` and `x_y_z_throughline.md`.

## Code and Rune Code

The live Code archive contains twenty-five pages. Rune Code is a seventeen-page subset sharing the *Octave* group/place coordinate key; other Code pages use unrelated mechanisms or remain unresolved. Membership and decoding status are separate fields in `01_inventory/code_register.csv`.

## Duets and secondary crossings

The live *Duets* archive contains all fourteen reflected-pair eponyms plus *Twist*. Riddles, Mathematical Esoterica, Past, Future, and Letter are recorded as secondary archive crossings in `01_inventory/secondary_series_register.csv`; membership alone does not assert a continuous prose order.

## Twist / Middle

The ten-entry Twist category is now complete as one direct path rather than two fragments: `ᛉ → Rune Casting: Eolhx → X is for → Fen → Twist → Loop → How to See the Pair in the Middle → Translating Eolhx → Stanza 15: Helix → The Middle`. Membership and archive position are recorded in `01_inventory/middle_register.csv`; interpretation is in `02_structure/middle_chapter_path.md`. This is an exceptional unpaired path, not a fifteenth reflected-pair braid.

## Glyph / rune pages

Pages titled by a rune glyph often contain carving instructions, sound/history, bodily or material description, and burial or protective use.

## Code, riddles, captions, and hidden matter

Code is both a declared component and a method of concealment. Image captions are compositional text, not accessibility debris. Riddles should be recorded before being solved; solutions and confidence belong in separate fields.
