# Page Capture Area

Future records should use one folder per canonical page slug:

```text
07_capture/
  page-slug/
    record.md
    links.csv
    media.csv
    claims.csv
    notes.md
```

`record.md` should preserve exact title, URL, dates, headings, rune/chapter/stream fields, and a rights-respecting text record. `links.csv` and `media.csv` preserve page order. `notes.md` is only for working inference; it must not overwrite observation.

No raw page text has been bulk copied into this seed. The present artifact is a topology and acquisition foundation.
